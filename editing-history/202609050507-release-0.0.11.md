# 发布 0.0.11 / Release 0.0.11

- 发布 Calcit 0.13.77 兼容版本，保持既有 watcher 回调、取消、资源生命周期、事件顺序与 C-safe native FFI 边界不变。

## English

- Release compatibility with Calcit 0.13.77 while preserving the existing watcher callbacks, cancellation, resource lifecycle, event ordering, and C-safe native FFI boundary.
