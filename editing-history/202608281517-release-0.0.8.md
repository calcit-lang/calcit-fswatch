# 发布 0.0.8 / Release 0.0.8

## 中文

- 发布基于 `calcit_native_ffi 0.1.2` 的 fswatch native 模块。
- 同步 Cargo crate 与 `deps.cirru` 模块版本为 0.0.8，修正模块元数据仍停留在 0.0.6 的偏差。
- 保持 async/resource/buffer protocol v1、Calcit 0.13.57 最低版本和 watcher 行为不变。

## English

- Release the fswatch native module backed by `calcit_native_ffi 0.1.2`.
- Synchronize the Cargo crate and `deps.cirru` module versions at 0.0.8, correcting module metadata that still reported 0.0.6.
- Preserve async/resource/buffer protocol v1, the Calcit 0.13.57 minimum, and watcher behavior.
