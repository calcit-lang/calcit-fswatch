# 发布 0.0.10 / Release 0.0.10

## 中文

- 发布双重有界的文件事件入口队列（256 个事件 / 1 MiB），取消 host coalescing 并保持 rename 路径与文件事件的源顺序。
- 溢出、watcher 错误和背压拒绝形成明确且唯一的失败 terminal；取消形成唯一完成 terminal，失败后要求消费者 rescan。
- 公开 API 返回 typed `FfiTask`，最低 Calcit 版本升级为 0.13.68。
- 覆盖确定性 burst/ordering/atomic-batch 测试及 Linux 真实 create/modify/rename/remove 生命周期。

## English

- Release the dual-bounded filesystem-event ingress (256 events / 1 MiB), disable host coalescing, and preserve source order for rename paths and file events.
- Produce one explicit failure terminal for overflow, watcher errors, or backpressure rejection, and one completion terminal for cancellation; consumers must rescan after failure.
- Return a typed `FfiTask` from the public API and raise the minimum Calcit version to 0.13.68.
- Cover deterministic burst, ordering, atomic-batch tests, and a real Linux create/modify/rename/remove lifecycle.
