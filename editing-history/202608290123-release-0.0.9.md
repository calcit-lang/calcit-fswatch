# 发布 0.0.9 / Release 0.0.9

## 中文

- 发布基于 `calcit_native_ffi 0.1.3` 的 fswatch native 模块。
- 删除模块内最后一份 queue-full retry loop，统一使用共享的可取消、deadline-aware `publish_emit_until`。
- 将 watcher smoke 从固定启动 sleep 改为等待真实 event 的 readiness probe，消除 OS watcher 注册时序导致的 flaky test。
- 同步 Cargo crate 与 `deps.cirru` 模块版本为 0.0.9，并保持 Calcit 0.13.58 门禁。

## English

- Release the fswatch native module backed by `calcit_native_ffi 0.1.3`.
- Remove the final module-local queue-full retry loop in favor of the shared cancellable, deadline-aware `publish_emit_until` helper.
- Replace the watcher smoke's fixed startup sleep with a real-event readiness probe, eliminating OS watcher registration timing flakiness.
- Synchronize Cargo and `deps.cirru` at version 0.0.9 while retaining the Calcit 0.13.58 gate.
