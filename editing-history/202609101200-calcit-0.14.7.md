# Calcit 0.14.7 严格模式 / Calcit 0.14.7 strict mode

## 中文

- 将 Calcit 最低版本升级到 0.14.7，并发布模块 0.0.12。
- 用 0.14.7 的默认严格诊断和零容忍质量门禁重新验证公开 API；保持既有的 C-safe native FFI 边界。

## English

- Raise the minimum Calcit version to 0.14.7 and prepare module release 0.0.12.
- Revalidate the public API with 0.14.7 default strict diagnostics and the zero-tolerance quality gate while preserving the existing C-safe native FFI boundary.
